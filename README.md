# KhataMitra – Updates

KhataMitra ek udhaar khata (ledger) app hai. Isme customers aur suppliers ka hisaab, reminders aur PDF reports hote hain.

Is repo mein sirf app ke APK updates hain.

## Download / डाउनलोड
1. Latest APK ke liye **Releases** section kholo.
2. Sabse naye release ki `.apk` file download karo.
3. Install karo. Phone puchhe to **"Install unknown apps"** ki permission de do.

## App ke andar update
App kholne par naya version hone par apne aap update ka message aata hai.
Aap **Settings → Check for Updates** se bhi dekh sakte hain.

## Note
- Update usi app par chalta hai jo pehle se install ho.
- Ye app abhi sirf personal use ke liye hai.
